# Articles Module

Version 1.0

---

# Purpose

Articles merupakan modul utama GrailDaily CMS.

Seluruh proses penulisan, pengeditan, revisi, SEO, publikasi, dan pengelolaan artikel dilakukan melalui modul ini.

---

# Objectives

- Membuat artikel baru.
- Mengedit artikel.
- Menyimpan draft.
- Menjadwalkan publikasi.
- Mempublikasikan artikel.
- Mengarsipkan artikel.
- Menghapus artikel.
- Restore artikel.
- Mengelola SEO.
- Mengelola Featured Image.
- Mengelola Categories.
- Mengelola Tags.
